# 기능 개발 파이프라인

사용자가 요청한 기능: $ARGUMENTS

아래 4단계를 순서대로 진행한다. 각 단계의 완료 조건을 만족하기 전에는 절대 다음 단계로 넘어가지 않는다.

## 1단계 — 구현 계획 (메인 세션이 직접, 사용자와 대화)

1. 관련 코드·docs/ARCHITECTURE.md·docs/CONVENTIONS.md를 충분히 탐색한 뒤, CLAUDE.md "작업 방식" 규칙대로 계획을 제안한다:
   - 목표 / 접근법 / 완료 기준
   - 현재 방식보다 나은 대안이 없는지 검토한 결과
   - 선택한 방식의 잠재적 문제점·트레이드오프
2. 사용자와 대화를 반복하며 계획을 다듬는다. 사용자의 피드백을 반영할 때마다 수정된 계획을 다시 보여준다.
3. **완료 조건: 사용자가 계획을 명시적으로 승인한다.** 승인 전에는 어떤 코드도 수정하지 않는다.
4. 승인된 계획을 구현 에이전트에게 그대로 전달할 수 있도록 완결된 형태로 정리한다: 변경/생성할 파일 목록, API 스펙(엔드포인트·요청·응답), 엔티티/스키마 변경, 작성할 테스트 항목.

## 2단계 — 구현 (implementer 서브에이전트, Sonnet)

1. 브랜치 준비: `git checkout develop && git pull` 후 `feature/{기능명}` 브랜치 생성.
2. Agent 도구로 `implementer` 서브에이전트를 호출한다. 프롬프트에 반드시 포함할 것:
   - 1단계에서 승인된 계획 전문
   - "CLAUDE.md와 docs/CONVENTIONS.md를 준수할 것"
   - "구현한 기능에 대한 단위 테스트를 반드시 작성할 것 (정상 동작 + 엣지 케이스)"
   - "완료 전 `./gradlew build`가 통과하는지 확인할 것"
3. 에이전트가 반환한 변경 파일 목록과 구현 요약을 확인한다. **이 에이전트의 ID를 기억해둔다** — 3단계 수정 루프에서 같은 에이전트를 이어서 호출하기 위함.

## 3단계 — 검증 (메인 세션이 주관)

다음 세 가지를 모두 수행한다:

1. **독립 코드 리뷰**: Agent 도구로 `reviewer` 서브에이전트를 호출한다. 프롬프트에 승인된 계획 전문과 `git diff develop` 결과(또는 변경 파일 목록)를 전달하고, 계획 충족 여부·컨벤션 위반·버그·엣지케이스·테스트 누락을 비판적으로 리뷰하게 한다.
2. **빌드·테스트**: `./gradlew build` 및 `./gradlew test`를 메인 세션이 직접 실행한다.
3. **실제 동작 확인**: 로컬 프로필로 부팅이 가능하면 애플리케이션을 띄우고 새 API를 직접 호출해 응답을 확인한다. 부팅이 어려우면 그 사유를 사용자에게 알린다.

**수정 루프** — 지적사항이나 실패가 있으면 **수정 규모와 무관하게 전부 implementer에게 맡긴다. 메인 세션은 코드를 직접 수정하지 않는다**:
- 2단계의 implementer 에이전트를 **새로 띄우지 말고 같은 에이전트 ID로 이어서 호출**해 수정을 맡긴다 (구현 맥락 재사용)
- 메인 세션은 리뷰 지적사항·빌드/테스트 실패 내용을 정리해 수정 지시만 전달한다 (수정자와 판정자 분리)
- 수정 후 1~3번 검증을 다시 실행한다. **완료 조건: 리뷰 통과 + 빌드·테스트 전부 통과.**

## 4단계 — Git 반영

1. 커밋: 한글 메시지, `feat:`/`fix:` 등 접두사 (CLAUDE.md 커밋 규칙).
2. `git checkout develop && git merge feature/{기능명}` → `git push origin develop`.
3. 머지 완료된 feature 브랜치 삭제.
4. `gh pr create --base main --head develop`으로 PR 생성. 본문은 docs/PR_TEMPLATE.md 템플릿 사용. 생성된 PR 링크를 사용자에게 보여준다.
5. **여기서 반드시 정지한다.** "main 머지 = 운영 배포이므로 확인이 필요합니다"라고 안내하고, 사용자가 명시적으로 머지를 지시한 경우에만 `gh pr merge`를 실행한다. 머지 후에는 develop이 최신 상태인지 확인한다.
